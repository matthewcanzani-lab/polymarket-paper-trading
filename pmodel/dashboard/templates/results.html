What I learned

  • My first version (June 2026) looked impressive in testing, with an 84% win rate and a +21% simulated return. But it used information that was not yet known when each prediction was made, such as a market's final trading volume, and it mixed up time periods. This mistake is called look-ahead bias, and it makes a model look far better than it is.
  • In this version the model may only use what was knowable at the moment of each prediction, it is tested on later months than it learned from, and every bet is logged before the outcome. When I removed the same leak here, an apparent +24% edge disappeared.
  • Polymarket's prices turned out to be accurate already, so beating them needs outside information. I'm now testing whether weather forecasts beat temperature markets, with every pretend trade priced at what it would really have cost.

How to verify

Every prediction is saved to a file in this public GitHub repository when it is made, and GitHub timestamps each save, so results can't be added after the fact. Each record is also linked to the one before it, so changing an old record would be detectable. See the full, timestamped history of predictions.
